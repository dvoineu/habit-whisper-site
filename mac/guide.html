HabitWhisper на Mac

Подключите Codex или Claude Code к задачам, привычкам и целям HabitWhisper. Компаньон работает в строке меню Mac; данные с iPhone получает через ваш iCloud.

Инструкция для распространяемой Production-версии · macOS 26 и новее · Mac с Apple Silicon (M1 и новее).

Перед началом. Нужны HabitWhisper на iPhone, один аккаунт Apple для iCloud на обоих устройствах и установленный на этом Mac клиент Codex или Claude Code. Xcode, исходный код и отдельный аккаунт HabitWhisper для установки не нужны. Development-сборки с тестовой средой iCloud используют другое облачное окружение.

1. Установите приложение

  1. На странице HabitWhisper для Mac скачайте DMG. Если эта инструкция открыта с установочного диска, приложение уже находится рядом с ней.
  2. Откройте DMG и перетащите HabitWhisper.app в Applications / Программы. Дождитесь завершения копирования.
  3. Извлеките установочный диск через Finder. Откройте Программы → HabitWhisper именно в Finder, не с установочного диска и не через среду разработки.
  4. Если macOS попросит подтвердить первый запуск скачанного приложения, выберите Открыть. Если система сообщает о повреждении или не может проверить разработчика, повторно скачайте файл с официальной страницы или обратитесь в поддержку.

Вариант с ZIP: распакуйте архив двойным щелчком в Finder, перенесите HabitWhisper.app в Программы и запустите оттуда. Устанавливать оба варианта не нужно.

Для проверки файла опытные пользователи могут скачать SHA256SUMS.txt с той же страницы и сравнить SHA-256 скачанного DMG или ZIP командой shasum -a 256 <путь-к-файлу>.

2. Найдите значок и дождитесь данных

  1. Найдите значок листа в строке меню вверху экрана и нажмите его. У приложения нет главного окна или постоянного значка в Dock — это обычное поведение компаньона.
  2. Убедитесь, что Mac и iPhone вошли в один аккаунт Apple для iCloud. Откройте HabitWhisper на iPhone, подключите оба устройства к интернету и дайте iCloud время на передачу данных.
  3. В меню Mac проверьте «Последнее получение из iCloud», количество задач и привычек на сегодня. Статус «Работает» означает, что локальный сервер готов принимать запросы; ожидаемые изменения с iPhone проверяйте отдельно.
  4. Оставьте «MCP-сервер» включённым. Для первого подключения выключите «Разрешить изменения»: агент сможет читать данные, а команды записи не будут доступны.

Не запускайте одновременно Development-копию и скачанную Production-копию. Если видны два значка листа, завершите старую копию через её меню. Адрес подключения обычно http://127.0.0.1:8765/mcp; используйте точный адрес, показанный в вашем меню.

3. Подключите Codex

Подключение предназначено для локального клиента на том же Mac. Облачная задача или клиент на другом устройстве не получит доступ к адресу 127.0.0.1.

  1. В меню HabitWhisper нажмите «Конфиг для Codex». В буфер обмена попадёт блок с адресом и вашим секретным токеном.
  2. Откройте личный файл ~/.codex/config.toml в текстовом редакторе. Символ ~ означает вашу домашнюю папку. Если каталога или файла ещё нет, создайте их. Сохраните существующие настройки.
  3. Добавьте скопированный блок один раз. Если раздел [mcp_servers.habitwhisper] уже есть, замените только его параметры; не добавляйте второй раздел с тем же именем. Пример ниже показывает форму, а не рабочий токен.
[mcp_servers.habitwhisper]
url = "http://127.0.0.1:8765/mcp"
http_headers = { Authorization = "Bearer <ваш-токен-из-меню>" }
  1. Сохраните файл и откройте новый локальный чат или перезапустите клиент, чтобы он перечитал конфигурацию. Для CLI можно проверить регистрацию командой codex mcp list; наличие записи ещё не подтверждает успешное чтение данных.
  2. Напишите: «Используй habitwhisper. Покажи задачи и привычки на сегодня. Ничего не меняй. Укажи часовой пояс и время последнего получения из iCloud». Сверьте ответ с iPhone.

Если используете другой каталог конфигурации Codex, измените файл активного профиля. Не сохраняйте токен в файле проекта, репозитории или общей папке.

4. Подключите Claude Code

  1. В меню HabitWhisper нажмите «Команда для Claude Code».
  2. Откройте Terminal в каталоге, где собираетесь работать с Claude Code, и выполните скопированную команду. Она регистрирует сервер habitwhisper с токеном. Пример формы:
claude mcp add --transport http habitwhisper http://127.0.0.1:8765/mcp --header "Authorization: Bearer <ваш-токен-из-меню>"
  1. Проверьте регистрацию командой claude mcp list и откройте новую сессию Claude Code в этом же каталоге.
  2. Если клиент просит разрешить подключение или использование инструментов, проверьте имя habitwhisper и локальный адрес, затем разрешите нужные операции.
  3. Попросите показать сегодняшний план без изменений и сравните ответ с iPhone.

Скопированная команда использует стандартную область настройки Claude Code для текущего проекта. Чтобы подключение действовало для вашего пользователя во всех проектах, добавьте к ней --scope user. Если клиент сообщает, что имя уже занято, удалите старую регистрацию через claude mcp remove habitwhisper в соответствующей области и выполните новую команду.

5. Используйте помощника

Начните с чтения

  • «Что у меня сегодня? Покажи задачи и привычки, ничего не меняй».
  • «Найди незавершённые задачи на эту неделю».
  • «Покажи мои цели и связанные с ними привычки».
  • «Как прошла эта неделя? Покажи факты и время последнего получения данных».
  • «Предложи порядок дел на завтра. Сначала только предложение, без изменений».

План и объяснения формирует выбранный вами агент по доступным данным. Компаньон сам не содержит модель и не запускает отдельного помощника.

Разрешите запись, когда будете готовы

  1. Включите «Разрешить изменения» в меню HabitWhisper.
  2. Откройте новый чат клиента, чтобы он заново прочитал доступные инструменты.
  3. Начните с отдельной задачи: «Создай задачу “Проверка Mac-компаньона” на завтра в 10:00».
  4. Проверьте название и срок в ответе, затем дождитесь появления задачи на iPhone.
  5. Попробуйте перенести эту задачу и отметить выполненной. Удаление попросите отдельно и подтвердите в клиенте.

Доступны чтение и изменение задач, подзадач, привычек, отметок и целей; также сводки и статистика. Для неоднозначного названия назовите точный объект и дату. Архивирование привычки сохраняет её прошлые отметки. Запросы удаления и архивирования формулируйте явно; не отключайте подтверждения клиента для таких операций.

После работы можно снова выключить «Разрешить изменения». Это блокирует запись на сервере, включая запросы из уже открытого чата.

6. Как работает синхронизация

Компаньон читает и сохраняет данные на Mac, а iCloud передаёт их между устройствами. Доставка занимает время и не гарантирована мгновенно. Для синхронизации нужны доступный iCloud, интернет и одинаковое облачное окружение на обоих устройствах.

  • «Последнее получение из iCloud» — время последнего подтверждённого импорта на Mac. В ответах MCP оно называется asOf. Это не время последней локальной записи и не подтверждение, что iPhone уже получил изменения с Mac.
  • «Ожидание данных из iCloud» означает, что подтверждённый импорт пока не зарегистрирован. Пустая сводка в этот момент не доказывает, что все данные отсутствуют.
  • «Обновить сводку» перечитывает уже доступную на Mac историю. Кнопка не заставляет iCloud немедленно скачать данные.
  • Если новых правок давно не было, старое время импорта само по себе не означает ошибку. Если ждёте конкретную правку, проверьте именно её на втором устройстве.

При проблеме не удаляйте хранилище и не повторяйте многократно команду создания задачи: сначала проверьте, не была ли она уже создана.

8. Доступ к данным и токен

Сервер слушает только 127.0.0.1 и требует токен. Открывать порт в роутере или подключать туннель не нужно. Дневник и личные ответы недельной рефлексии через MCP не предоставляются; произвольного доступа к файлам, SQL и Terminal сервер не даёт.

Когда вы подключаете клиента, выбранный агент получает запрошенные данные задач, привычек и целей. Его провайдер может обрабатывать их на своих серверах согласно вашим настройкам и его политике. Локальный адрес компаньона не означает, что модель работает локально. До подключения ознакомьтесь с условиями выбранного клиента и политикой HabitWhisper.

Токен хранится в Связке ключей macOS; скопированные настройки содержат его текст. Не отправляйте их в чат, поддержку или репозиторий. Команда Claude Code также может сохраниться в истории Terminal. При раскрытии токена нажмите «Новый токен», подтвердите замену и обновите настройки клиентов. Для немедленной остановки доступа выключите «MCP-сервер».

9. Обновление и удаление

Обновление

  1. Скачайте новую версию с официальной страницы. Завершите текущую через «Завершить HabitWhisper».
  2. Замените приложение в той же папке Программы и откройте его в Finder. Не удаляйте контейнер данных или записи Связки ключей.
  3. Проверьте статус, данные и автозапуск. Если ранее использовалась копия в другой папке, выключите автозапуск старой копии перед переносом.
  4. Откройте новый чат агента для обновления каталога инструментов. При прежнем токене и адресе повторная настройка обычно не требуется.

В текущей версии нет встроенного автоматического обновления.

Отключение и удаление

  1. Выключите «Разрешить изменения» и «Запускать при входе», затем завершите HabitWhisper.
  2. Для Codex удалите только раздел [mcp_servers.habitwhisper] из активного личного конфига. Для Claude Code выполните claude mcp remove habitwhisper в той области, где добавляли сервер; для пользовательской настройки — claude mcp remove --scope user habitwhisper.
  3. Переместите HabitWhisper.app из Программ в Корзину. Это не является командой удаления ваших задач, привычек и целей из iCloud. Локальные данные и токен могут остаться на Mac; полное удаление личных данных обсуждайте с поддержкой отдельно.

HabitWhisper for Mac

Connect a local Codex or Claude Code client to your HabitWhisper tasks, habits and goals. The companion lives in the Mac menu bar and syncs with your iPhone through your iCloud account.

Requires macOS 26 or later, an Apple Silicon Mac (M1 or later), HabitWhisper on iPhone, the same Apple Account for iCloud on both devices, and a client installed on this Mac. No Xcode or source code is needed. Production and Development iCloud environments are separate.

Install and start

  1. Download a DMG from the official Mac page, open it and drag HabitWhisper.app to Applications. If reading this on the mounted disk, the app is beside this guide. Alternatively, unzip the ZIP and move the app to Applications.
  2. Eject the disk, then launch the installed app from Finder. Confirm the normal first-launch Open prompt. If macOS cannot verify the developer or reports damage, download again or contact support.
  3. Click the leaf in the menu bar. There is no main window or permanent Dock icon. Keep only one companion copy running.
  4. Open HabitWhisper on iPhone, check your network and iCloud account, and wait for the import. Running means the local server is ready; check expected iPhone changes separately.
  5. Keep MCP server on and turn Allow changes off for your first connection.

Connect Codex

  1. Click Codex config in the companion menu.
  2. Paste the copied block into your personal ~/.codex/config.toml. Create the file if needed and preserve other settings. Replace an existing [mcp_servers.habitwhisper] section rather than duplicating it. Use the active configuration if you customized its location.
[mcp_servers.habitwhisper]
url = "http://127.0.0.1:8765/mcp"
http_headers = { Authorization = "Bearer <your-token-from-the-menu>" }

This example is a template; use the real port and token copied by the app. Start a new local chat or restart the client. codex mcp list checks registration, not successful data access. Ask: “Use habitwhisper to show today's tasks and habits. Make no changes. Include the time zone and last confirmed iCloud import time.” Compare with your iPhone. Cloud tasks and clients on other devices cannot access this Mac's loopback address.

Connect Claude Code

  1. Click Claude Code command and run the copied command in Terminal in the project directory where you will use Claude Code.
claude mcp add --transport http habitwhisper http://127.0.0.1:8765/mcp --header "Authorization: Bearer <your-token-from-the-menu>"

The command uses Claude Code's default project-local scope. Add --scope user for all your projects. If the name already exists, remove its old registration in the matching scope before adding it again. Check claude mcp list, open a new session, approve the intended local tools if prompted, and try the same read-only request.

Read first, then allow changes

Try “What is planned for this week?”, “Show my goals and linked habits” or “Summarize this week's progress with the import time.” Your selected agent generates advice from the available data; the companion has no built-in model.

  1. Turn on Allow changes when ready and open a new chat to refresh the tool catalog.
  2. Ask the agent to create a clearly named test task for tomorrow at 10:00.
  3. Verify its title and date, then wait for it to appear on iPhone.
  4. Try moving and completing this same task. Request deletion separately and confirm it in your client.

Tasks, subtasks, habits, habit logs, goals, summaries and statistics are available. Habit archiving preserves earlier logs. Be explicit about the object and date. Keep client confirmations for deletion and archiving. Turning Allow changes off blocks server writes even from an existing chat.

Understand iCloud freshness

Last received from iCloud, or asOf in tool responses, is the last confirmed import on this Mac. It is not the last local write time and does not prove that iPhone has received a Mac change. Waiting for iCloud data means an import has not been recorded yet. An old timestamp can be normal when there have been no new changes.

Refresh summary rereads data already imported on the Mac; it does not force an immediate cloud download. Keep the devices online and verify the specific expected change. Avoid deleting your local store or repeatedly creating the same task while waiting.

Menu controls and privacy

  • MCP server starts or stops local agent access. Turning it off does not by itself stop the running app's iCloud sync.
  • New token replaces the secret after confirmation. Copy and replace the connection settings in every client afterward.
  • Recent actions shows recent agent writes, not every read or delivery to iPhone.
  • Launch at login starts the installed copy after login. Approve it in System Settings → General → Login Items & Extensions if requested.
  • Quit HabitWhisper stops the app and local server. The app must be running and the Mac awake for agent access.

The server accepts requests only on 127.0.0.1 with a token. Do not expose it with port forwarding or a tunnel. Journal entries and private weekly reflection answers are unavailable through MCP, as are arbitrary file, SQL or shell access.

Your chosen client receives requested task, habit and goal data and may send it to its model provider under that provider's terms and your settings. A local companion does not imply a local model. Read the privacy policy and your client's policy before connecting.

The token is stored in macOS Keychain. Copied settings contain it as text, and a pasted command may remain in shell history. Never share your token or commit your client config. If exposed, rotate it with New token and replace every client's settings. Turn off MCP server to stop access immediately.

Update or uninstall

There is no built-in automatic updater. Download a new version, quit the installed copy, replace it in the same Applications folder and launch from Finder. Keep the data container and Keychain item. Check your data and login setting, then start a new agent chat. With the same endpoint and token, reconnection is usually unnecessary.

To uninstall, turn off Allow changes and Launch at login, quit the app, remove only its Codex configuration section and/or run claude mcp remove habitwhisper in the configured scope (--scope user for a user registration), then move the app to Trash. This is not an instruction to delete your iCloud tasks, habits or goals. Local data and the token may remain.

Troubleshooting

  • No window: use the menu bar leaf. Check hidden menu items and launch from Finder.
  • No iCloud access: read the message in the menu, check sign-in and network, then use Try again. Production and Development builds use separate environments.
  • Stale or empty data: wait for the expected import with iPhone open and online, then refresh. Do not clear the database.
  • Connection refused: wake the Mac, launch the companion, turn on the server and check its exact address and port.
  • 401 / Unauthorized: copy fresh settings from the menu and replace the client's token.
  • Writes denied or unknown tool: check Allow changes and open a new chat. Update the companion if needed.
  • Two icons or port conflict: quit the old or duplicate copy and retry the server.
  • Login launch fails: install in Applications and check the macOS Login Items approval. Do not register the app from a mounted DMG.
