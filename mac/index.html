Как установить и подключить

Что понадобится

Mac с чипом M1 или новее, macOS 26 или новее, HabitWhisper на iPhone и один аккаунт Apple для iCloud на обоих устройствах. Клиент Codex или Claude Code устанавливается отдельно на тот же Mac.

Начните с чтения

Спросите, что запланировано на сегодня, как прошла неделя или какие привычки связаны с целью. Изменения можно разрешить отдельным переключателем в меню компаньона.

Дневник недоступен через MCP. Выбранный вами агент получает запрошенные данные; их обработка его провайдером зависит от настроек и условий клиента. Синхронизация iCloud может занимать время.

Install and connect

Requires macOS 26 or later, Apple Silicon (M1 or later), HabitWhisper on iPhone and the same Apple Account for iCloud. Install Codex or Claude Code separately on this Mac.

Start with read-only access and enable changes in the menu when ready. Journal entries are unavailable through MCP. Your chosen agent receives requested data under its provider's terms and your settings. iCloud delivery takes time.
